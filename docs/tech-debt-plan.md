## 1. Summary — where the debt concentrates

1. **The rules are enforced by memory, not tooling.** `.dependency-cruiser.cjs` has no layer rule at all (only `no-circular`, `not-to-unresolvable`, `no-orphans` as _warn_), `eslint.config.js` has no `no-restricted-imports` / `no-restricted-syntax`, `no-explicit-any` is `warn` (so CI cannot fail on it), and a config-ordering bug silently downgrades `react-hooks/exhaustive-deps` from the intended `error` back to `warn`. Every single-source rule in CLAUDE.md ("never a raw palette name", "every path through `lib/urls.ts`", "every read passes `cache`", "components never import server modules", "never a bare `<img>`") can be broken by a new file with every gate green. The violations in this plan are the proof: `href="/cart"` in the header, `text-ember` without a comment on two cart error lines, `text-red-600` on the contact form, two `/drops/…` literals, four bare `<img>`s, eight of fifteen loaders discarding GraphQL `errors`. PRs 10–11 close this.

2. **One shared helper silently drops a brand value.** `cn()` is stock `tailwind-merge`, whose default config treats `text-*` as conflicting with `leading-*`, so `Heading`'s brand `leading-[1.1]` is evicted by three of its own four size presets and by every caller that passes a `text-*` (eleven headings render at Tailwind's per-size line-height instead of the brand's 1.1). The rule file blames CSS ("`text-*` also sets `line-height`") and teaches a workaround — repeat the leading beside every size step — that is a Tailwind v3 fact, so every responsive heading carries two to five copies of one value. One-line fix in `lib/cn.ts`, then ~40 redundant utilities and seven comments go. PR 6.

3. **Loader and server boilerplate has no helper.** Fifteen `graphql()` call sites hand-roll `{ data, errors }` → log → null-check three different ways; eight never log `errors`; `naming-conventions.md` documents a `getX`/`getXOrThrow` pattern that no code implements; three inline `throw new Response(…)` bypass `lib/http.ts`; the PDP canonical is emitted as an invalid `<meta rel="canonical">` with a relative path; two actions implement the same 405/400 contract by hand; robots.txt is 75 lines of text generation inside a route. PR 3.

4. **Recipes retyped at call sites instead of shared devices.** The same class strings appear in two to six files: the error-page frame (root + NotFound, byte-identical 31-token string), `GradedMedia` (two files, the second says it copied the first), the 300-character "file grid" background, the type-on readout + Ember caret, the segmented size cell (ProductForm + SizeGuide, already drifted), the 15% legibility wash (three verbatim copies cross-referencing each other in comments), the mono spec strip (six hand-rolled copies beside `SpecLine`), the under-header hero shell, sub-12px font sizes written as eight different arbitrary values, the brand 2px radius typed three times while the token says 10px. PR 7.

5. **Images that bypass `common/Image`.** `MediaSlot`, `SizeGuide`, `CartLineItem` (wrong mode: `w-20` is dead under the inline width, ladder is upscaled), and `TeaserSection`'s below-the-fold autoplay `<video>` — every `/drops/baseline`, `/drops/first-light` and Our Story photo is a single fixed-width CDN file downscaled by the browser, the exact path common-pitfalls documents as the knit-aliasing cause. Plus a Hydrogen-skeleton `@layer base` block (`form { max-width: 400px }`, `input`, `li`, `dl`) that seven call sites opt out of and two forgot to. PRs 8–9.

6. **Content with hidden duplicates and dead features.** Seven athlete files repeat 15 identical chrome strings; "Designed in San Francisco" lives in eight files; three product prices are hand-typed in two files; the drop-02 teaser (`/drops/first-light`, `DropTwo`, countdown, waitlist list) has been flagged off since September with its date passed and every panel still a placeholder; `HOME_HERO.coordinates/tagline` are parked behind a JSX comment; a `starting-lineup` anchor has no link; `camLine`/`captions` are empty on all seven athletes. PRs 1, 4 and §4.

7. **Docs that disagree with each other and the code.** Four descriptions of "the gate" (ci.yml, `/check`, README, playbook) differ; `/check` step 1 expands to `prettier --write . --write <files>`; `/review_pr` is registered as `review-pr`; `.cursor/rules/code-style.mdc` has drifted by nine rules from `.claude/rules`; `migration-status.md` is a stamped-historical file with false rows; `migration-playbook.md` carries its own drifted copy of the conventions and a machine path that does not exist; ADRs 0005/0008/0010 point at retired files without an addendum; CLAUDE.md names Hydrogen `Image`/`Money` exports that no longer exist; the same trap is told in up to seven places (autoConfig ×3, Traffic Permissions ×5, explicit-cache ×8).
